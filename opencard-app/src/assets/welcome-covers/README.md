# 欢迎页内置封面素材

`welcome-covers` 目录下的图片只用于欢迎页背景的封面墙：即使没有任何用户项目，背景也有足够的内容。它们通过 `src/features/shell/welcomeCoverArtwork.ts` 引入。

## 版权说明（重要）

这些图片是**第三方桌游产品盒面的缩略图**，版权归各自发行商与美术作者所有，**不是** OpenCard 的资产，也没有任何授权。当前仅作为开发阶段的背景占位素材，经项目所有者确认后按现状保留。

随应用对外分发前必须处理其中之一：

- 替换为自有或已授权的美术；
- 或删除本目录内容并更新 `welcomeCoverArtwork.ts`（封面墙会自动退回“用户项目封面 + 色块”）。
