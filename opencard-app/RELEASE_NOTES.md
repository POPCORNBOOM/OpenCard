## 改进

- 配置项目图标时可以直接点击项目文件路径重新选择精灵表，不再需要使用路径旁边的独立按钮。
- 版本管理侧栏现在会跟随当前打开的项目文件，显示所有修改过该文件的提交记录，并支持手动刷新。
- 点击提交记录可以进入只读对比模式，在分视条与左右双视图之间切换；两个版本共享缩放和平移，并直接看到新增、删除、修改和移动区块的彩色边框与加减标记。
- 对比区块结构树会使用绿色标题标识新增区块，使用红色标题标识已移除区块。
- 工作区操作栏现在可以混排操作按钮与只读文字；版本对比时会在选择按钮旁显示历史版本的提交短哈希，便于确认对比范围。
- 卡牌设计器的快捷键现在由编辑器全局接收；点击树、面板或画布后无需重新把焦点移回编辑器即可继续使用快捷键。

## 修复

- 首次点击文件时间线即可正确打开对比，不再短暂提示无法加载；切换到 README 等其他文件后，对比内容也不会串用上一个卡牌文件的版本。
