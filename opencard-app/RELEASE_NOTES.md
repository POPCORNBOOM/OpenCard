## 新增

- 自定义块现在可以作为 `.ocblock` 内容包安装和分享；安装后会展开到项目的 `.opencard/blocks/发布者/块名/` 目录，包信息、块定义和资源都可直接查看。
- 自定义块可以嵌套使用其他自定义块。导出的内容包会带上所需的嵌套块、图片、字体和图标，在没有源项目资源的环境中也能独立使用。
- 自定义块导出窗口现在以“包内容”和“预览与属性”分页组织工作：被块引用的字段会自动开放给使用者，字段与资源使用一致、清晰的类型和选择图标；可在沿用源卡面尺寸的即时预览中调整公开字段示例值、选择图片、字体、图标和嵌套块并检查缺失资源或循环引用，属性修改和资源排除都会立即反映在预览中。
- 在 CDE 或富文本中编辑自定义块时，属性面板会按照内容包公开的字段定义提供与普通块一致的体验；未覆盖的字段可以按需添加，内容包默认值会作为初始值，额外字段仍会保留在“其他”分类中。内容包设定的宽高调整权限也会同步作用于属性面板和画布调整手柄。

## 改进

- 已安装自定义块页面现在将公开字段属性固定显示在预览右侧，便于一边查看效果一边调整示例值；列表信息也更加精简，不再重复显示安装路径。
- 自定义字段现在默认可以绑定并供其他字段引用；属性面板中的只读、隐藏和输入限制不再改变字段的绑定能力。
- 块的显示规则现在与属性面板配置相互独立；调整附加字段的编辑控件、范围或选项，不再改变宽高、颜色等内置属性的实际显示与异常值回退结果。
- Git 变更列表现在会在文件名右侧稳定显示状态图标：新增显示绿色加号，删除显示红色减号，修改显示黄色圆点；窄侧栏中的长文件名会正确省略，悬停时可查看完整名称。连续文件变化会合并刷新，切回应用或打开版本控制面板时也会自动同步。刷新失败时会保留上次结果并标记为过期。尚未启用 Git 的项目会隐藏时间线和版本树，改为提供“初始化仓库”按钮，并可在弹窗中设置提交者信息后直接启用版本管理。
- 编辑器现在可以直接并排查看图片、项目字体与图标配置文件、字体文件的前后版本；图片对比支持同步缩放、平移和像素化预览，便于确认资源变化。
- 侧边栏中的空列表现在会在可用区域中央说明内容来源，例如打开的项目文件会出现在“打开的编辑器”中，当前文件的提交记录会出现在“时间线”中。
- CDE 数据表的预览浮窗不再显示选中块，并会始终显示在固定表头之上。
- CDE 现在会分别记住卡牌正面与背面的块选中状态，切换编辑器或翻转卡面后可以回到对应的编辑上下文。
- CDE 现在可以通过结构树右键菜单或 Ctrl/Cmd+C、Ctrl/Cmd+V，在不同卡面和打开的编辑器之间复制粘贴块，并保留完整嵌套结构。
- CDE 粘贴块时不再弹出浏览器剪贴板授权询问。
- 改进多个右键菜单的操作分组，让编辑、复制、移动和删除等操作更容易区分。
- 调整侧边栏宽度时会即时跟随拖拽，并保持在合理范围内，不再出现滞后的过渡动画；拖拽触发展开或收起时仍会平滑切换。
- 界面中的名称、状态、版本和路径等组合信息现在改用空格分隔，文字显示更简洁。

## 修复

- 已安装自定义块页面的列表和预览区域现在会正确填满可用高度，不再挤在页面顶部。
- CSS 长度字段现在可以正确接受负数值，不再错误显示渲染警告。
- 树形列表的操作浮窗现在会直接出现在触发位置，不再从窗口左上角闪现。
- 未选择项目图标集时，右侧的提示现在会正确显示在可用区域中央。
- 侧边栏树在节点内容与空状态提示之间切换时会保持可用高度，刷新时间线等内容时不再引起面板抖动。
- 未启用 Git 的项目不再短暂显示“正在加载时间线”，打开或切换编辑器时侧边栏中的其他列表也不会因此跳动。
