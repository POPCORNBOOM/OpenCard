## 新增

- 设置中新增“导出 CDE 表格后自动打开”开关，可控制导出 Excel 表格后是否立即使用系统默认程序打开。
- CDE 表格新增卡牌预览；选中或编辑字段单元格时，会自动显示对应蓝图或实例的卡面，并支持沿用设计器的缩放、平移和适配操作。
- 卡牌树支持按住 Ctrl/Cmd 或 Shift 选择多个卡牌实例，并可通过右键菜单批量复制或删除。
- 打开的编辑器列表支持使用鼠标中键快速关闭编辑器；存在未保存内容时仍会进入保存确认流程。
- 打开或保存卡牌时，字段值会保留用户输入；当颜色、路径、尺寸、枚举或对象结构不适合渲染时，编辑器和问题面板会明确标出警告，并在卡面上使用安全回退值。

## 改进

- 侧栏可在“工作区”和“版本管理”等树视图组之间切换，通过带图标和标题的顶部按钮左右滑动进入对应内容。
- 版本管理历史现在会在同一棵树中显示分支和提交；当前分支会突出显示，并标注其指向的提交短哈希。
- 版本管理侧栏现在会跟随当前打开的项目文件，显示所有修改过该文件的提交记录，并支持手动刷新。
- 点击提交记录可以进入只读对比模式，在分视条与左右双视图之间切换；两个版本共享缩放和平移，并直接看到新增、删除、修改和移动区块的彩色边框与加减标记。在左右双视图中，将指针悬停在修改或移动的区块上，还会显示连接两个版本对应区块的警告色曲线箭头。
- 对比区块结构树会使用绿色标题标识新增区块，使用红色标题标识已移除区块。
- 工作区操作栏现在可以混排操作按钮与只读文字；版本对比时会在选择按钮旁显示历史版本的提交短哈希，便于确认对比范围。
- 卡牌设计器的快捷键现在由编辑器全局接收；点击树、面板或画布后无需重新把焦点移回编辑器即可继续使用快捷键。
- 侧栏同时展开多个列表时会平分可用高度，各列表可独立滚动并能拖动分隔线调整高度。

## 修复

- 底部“问题”和“输出”面板收起时会将键盘焦点移回展开按钮，不再让焦点停留在隐藏内容中。
- 对比模式下不再允许通过菜单或 Ctrl/Cmd+Z、Ctrl/Cmd+Y 修改编辑器历史。
- 首次点击文件时间线即可正确打开对比，不再短暂提示无法加载；切换到 README 等其他文件后，对比内容也不会串用上一个卡牌文件的版本。
- 卡牌设计器会等待卡面图片和二维码等视觉资源完成加载或生成后再整体淡入，减少打开文件时占位内容和未完成画面的闪烁；资源加载失败也不会阻塞编辑器显示。
- 版本对比的属性面板现在只显示实际发生变化的字段；已删除区块也可以从结构树中选中并查看旧属性，移动、换层级和排序变化会显示对应的布局差异。
- 版本分界线移除了圆形拖动柄，并在线条两侧直接显示提交短哈希和提交标题，磁盘侧明确显示“磁盘版本”。
- 版本对比现在会从历史版本的项目资源目录正确加载项目字体、项目图标以及自定义块及其字体和图标；缺失、损坏或长时间无响应的单个视觉资源不会再使页面保持空白。
- 富文本中的自定义块现在沿用卡面自定义块的尺寸、背景、边框、透明度和布局样式，内联与块级嵌入也能保持正确排版。
- 欢迎页“最近打开的项目”等侧栏列表恢复平滑的展开和折叠动画。
