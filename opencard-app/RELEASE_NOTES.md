## 改进

- 欢迎页的最近项目列表现在会在项目名称后持续显示完整路径，查找同名项目时更容易确认位置。
- CardEditor 设计视图的左右面板现在以统一的玻璃浮层覆盖画布，支持鼠标、触控和键盘调整宽度与分栏高度；拖拽响应不再额外延迟，面板按钮的收起与展开保留自然过渡，收起后重新展开会恢复之前的面板宽度，窄窗口会自动收起面板，同时保留边缘恢复入口。画布缩放、比例文字、分隔线和操作按钮也统一由同一套工具条定义驱动。
- 自定义块注册表新增实时预览工作台，可以在同一界面选择已注册的自定义块、调整公开字段并查看包含包内图片的完整渲染效果；预览值不会修改包或项目文件，设计画布与导出也会使用一致的包内资源。
- 自定义块包升级为独立清单、原生 Block 与包内资源结构；名称和注释会始终开放，其余可编辑字段可在导出时选择，并可单独控制宽度和高度。字段选择区域会限制高度，字段较多时可直接滚动查看。图片、字体和图标按包隔离，嵌套导出会自动收集为自包含资源，直接预览中的父级字段引用也可正常解析。项目打开时仅加载包清单，实际使用时再按需加载内容，并自动释放长期未使用的资源；包或卡牌中多余、缺失及局部无效的内容会尽量忽略或补全，不再阻止其余可用内容打开和导出。
- 图标注册表的预览和自定义块注册表的公开字段现在使用可收起、可调整高度的半透明浮层；两处浮层与 CardEditor 共用外置调整轨道，双击轨道即可收起或恢复面板，画布缩放、聚焦和工具栏会自动避开浮层，悬浮工具条的四边留白也保持一致。
- 字体预览器和自定义块注册表现在与字体、图标注册表使用统一的标题栏样式、间距和主题颜色。
- 项目文件树现在将字体、图标、自定义块和字典注册表以简洁名称收纳在“项目配置”下面，相关项目文件更容易集中查看。
- 项目图标、自定义块与字典现在分别使用更容易辨认的贴纸、积木和翻译图标。
- UI 中的快捷键提示现在会在工具提示和操作菜单中统一显示为薄层叠高的软键盘按键，带图标、代码和换行的说明也会在不同入口保持一致，不再露出原始标记。
- 新建项目的左侧资源目录现在只保留模板、图标包和自定义块三棵树；内置模板直接显示在根部，我的模板集中在独立分组中，图标包与自定义块则直接平铺。
- 自定义块现在可以导入到 OpenCard 资源库，后续创建项目时可从列表中加入并注册；与模板中已有相同 Key 的自定义块会被拒绝，避免重复注册。
- 新建项目的模板详情和创建表单改为更紧凑的工作区排版，名称、入口、图标包和自定义块信息可以直接对照确认。
- 项目文件树中的文件夹现在使用统一的关闭与打开图标，并在两种状态下保持黄色，展开状态更容易辨认。
- 项目字体编辑器现在将“项目字体”和“字体组合”合并到同一棵常展开的树中，并固定提供两个添加按钮，添加、配置和预览两类条目时无需切换页面。
- 删除操作现在统一使用垃圾桶轮廓图标，视觉含义更加一致。
- 应用现在会在后台按计划检查反馈回复，并在“帮助”和“我的反馈/建议”上显示未读数量；查看具体回复后对应角标会自动更新。
