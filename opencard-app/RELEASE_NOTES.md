# 新增

- 新增统一的软件错误编号系统；输出栏中的错误现在仅显示可查询的错误码和含义，点击错误块仍可复制完整诊断信息，具体解决方案可在错误码文档中查阅。
- 工作区下方的“输出”栏现在会集中显示应用日志，可按调试、日志、信息、警告和错误筛选，并支持一键清除；每条消息独立成块，点击即可复制完整内容。
- 字体文件现在可以直接在工作区中输入文字预览字形效果，无需先注册到项目。
- 没有内置编辑器的文件现在会先显示打开方式提示，可选择以只读文本查看或交给系统默认程序打开。
- Excel 数据表导入现在会先显示变更摘要；可通过编辑“块名”列批量重命名块，也可在右侧新增以实例名为表头的列来创建实例。
- 清空 Excel 中的实例数据单元格即可移除覆写并恢复继承蓝图值，不再需要手动输入引用公式。

# 改进

- 数据表中的根 Block 现在会相对卡面缩进一级，子 Block 和字段继续按实际层级递进，正反面显示规则一致。
- 导出的 Excel 数据表现在会锁定字段身份和内部元数据，开放块名、数据区域与新增实例列；布尔和有限选项字段会提供下拉选择。
- Excel 导出完成后不再弹出系统消息框，工作区中的导入和导出按钮也改用方向相反的表格箭头图标。

# 修复

- 修复发行版中字体文件可能无法加载到预览器的问题。
- 修复切换内置配色或自定义背景色后，数据表中的 Block 行仍残留默认深色背景的问题。
