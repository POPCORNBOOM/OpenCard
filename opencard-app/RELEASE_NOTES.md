- 项目内部资源配置现在统一使用 `.opencard` 下的 `project.json`、`fonts/fonts.json`、`icons/icons.json`、`blocks/blocks.json` 和 `locale.json`；资源包使用 `.ocpack`，自定义块结构使用 `.ocblock`。
## 新增
- CDE 切换到数据表视图时，会先展开并淡出设计画布，再将卡牌预览平滑收回到上次记住的位置和尺寸。

- 开发环境的帮助菜单新增 CDE 调试开关，可持续隐藏编辑器浮层，方便观察纯画布布局。
- 开发环境的帮助菜单新增两个 CDE 调试开关，可分别暴露上层背景，或将画布切换为不响应点击的纯展示状态。
- 外部包管理页面现在支持导入本地 `.ocpack`，并查看项目声明与已安装包的差异。
- 文件菜单现在提供“制作包”工作台：可按资源类别选择 `blocks.json` 注册的自定义块、`fonts.json` 注册的字体、`icons.json` 注册的图标集和项目图片，填写包信息并制作 `.ocpack`；内部协议清单不会被误选入包内容。
- 导出的 `.ocblock` 现在可以重新导入项目；块 Key 会按独立结构定义格式保存，不再携带 `block:` 身份前缀。

- 资源引用现在统一支持当前环境、宿主项目和可见资源包作用域；包内资源不会因为同名而误解析到其他包，非法路径和不可用资源会稳定显示为不可用。
- 富文本中的字体和图标引用现在使用统一资源语法校验，资源包限定引用不会被误当作当前项目资源。
- 卡面字体引用现在也按统一资源规则解析，支持资源包限定字体并隔离同名字体。
- Markdown 和富文本中的图标现在会逐个按其实际来源解析，同一段内容可以混用项目图标和资源包图标。
- 卡面设计器中的字体补全现在使用统一资源环境快照，也会显示当前可见资源包中的字体引用。
- 自定义块导出分析现在会复用统一的资源引用规则，字体和图标依赖会按实际引用自动纳入资源清单。
- 自定义块导出时会保留作者明确选择的动态资源声明；重新注册 `.ocblock` 后这些声明仍然可用。
- 自定义块依赖分析现在会记录每项资源的引用来源；宿主项目引用会生成依赖诊断，资源包限定引用会记录对应的子包依赖。
- 新增 `.ocpack` 安装能力：打开或拖入资源包时会校验归档路径、JSON 和内容摘要，并安全、原子地展开到项目资源包目录；升级需要确认，取消后保留原版本。
- 资源包卸载现在会先检查其他已安装包的依赖关系；取消影响确认时保留原包，确认后才删除并刷新资源环境。
- 运行时展开自定义块时会按所属资源环境解析嵌套块和资源；公开字段覆盖会经过安全校验，嵌套内容继续使用普通卡面渲染和字段诊断。
- 自定义块现在以纯 JSON `.ocblock` 结构文件注册和分享；导入后会登记到项目的 `.opencard/blocks/blocks.json`，块定义不再携带资源字节、发布者或版本信息。
- 资源包使用独立的 `.ocpack` 运输格式；资源、共享块和版本信息不再混入单个 `.ocblock` 文件。
- 新增资源包构建工作台：可以选择多个自定义块和项目共享资源，填写包名称、Key 与版本，并将内容保存为 `.ocpack`。
- 自定义块导出窗口现在以“块结构”和“预览与属性”分页组织工作：被块引用的字段会自动开放给使用者，字段与资源使用一致、清晰的类型和选择图标；可在沿用源卡面尺寸的即时预览中调整公开字段示例值、选择图片、字体、图标和包内块并检查缺失资源，属性修改和资源排除都会立即反映在预览中；字段和资源树默认收起，需要时可通过“高级设置”展开。
- 在 CDE 或富文本中编辑自定义块时，属性面板会按照结构文件公开的字段定义提供与普通块一致的体验；未覆盖的字段可以按需添加，结构文件默认值会作为初始值，额外字段仍会保留在“其他”分类中。宽高现在与普通字段一样，通过公开状态和只读约束控制属性编辑与画布调整。

## 改进

- 文档保存现在会完整保留编辑器内存中的字段数据；自定义块实例字段不会因为保存或重新打开文档而被存储层过滤或改写。

- 项目管理树中的字体、图标和自定义块现在只显示配置入口，不再展开其中的资源文件；项目管理也不再提供清理未使用字体或图标的操作。
- 项目管理区域现在会显示外部包目录，已安装的 `.ocpack` 可以从项目结构中直接查看。
- 项目管理中的固定入口名称简化为项目、字典、字体、图标和自定义块，外部包在中英文界面中使用一致的名称和包图标。
- 自定义块导出工作台的分页现在位于高级设置区域，默认界面更紧凑；块结构的宽度和高度现在按普通字段的公开状态保存，未公开时会写入只读约束。
- 已安装自定义块页面现在将公开字段属性固定显示在预览右侧，便于一边查看效果一边调整示例值；列表信息也更加精简，不再重复显示安装路径。
- 自定义字段现在默认可以绑定并供其他字段引用；属性面板中的只读、隐藏和输入限制不再改变字段的绑定能力。
- 块的显示规则现在与属性面板配置相互独立；调整附加字段的编辑控件、范围或选项，不再改变宽高、颜色等内置属性的实际显示与异常值回退结果。
- Git 变更列表现在会在文件名右侧稳定显示状态图标：新增显示绿色加号，删除显示红色减号，修改显示黄色圆点；窄侧栏中的长文件名会正确省略，悬停时可查看完整名称。连续文件变化会合并刷新，切回应用或打开版本控制面板时也会自动同步。刷新失败时会保留上次结果并标记为过期。尚未启用 Git 的项目会隐藏时间线和版本树，改为提供“初始化仓库”按钮；初始化时可以设置提交者信息，并可选择立即创建包含当前项目文件的首次提交。
- 编辑器现在可以直接并排查看图片、项目字体与图标配置文件、字体文件的前后版本；图片对比支持同步缩放、平移和像素化预览，便于确认资源变化。
- 侧边栏中的空列表现在会在可用区域中央说明内容来源，例如打开的项目文件会出现在“打开的编辑器”中，当前文件的提交记录会出现在“时间线”中。
- CDE 数据表的预览浮窗不再显示选中块，并会始终显示在固定表头之上。
- CDE 现在会分别记住卡牌正面与背面的块选中状态，切换编辑器或翻转卡面后可以回到对应的编辑上下文。
- CDE 现在可以通过结构树右键菜单或 Ctrl/Cmd+C、Ctrl/Cmd+V，在不同卡面和打开的编辑器之间复制粘贴块，并保留完整嵌套结构。
- CDE 粘贴块时不再弹出浏览器剪贴板授权询问。
- 改进多个右键菜单的操作分组，让编辑、复制、移动和删除等操作更容易区分。
- 调整侧边栏宽度时会即时跟随拖拽，并保持在合理范围内，不再出现滞后的过渡动画；拖拽触发展开或收起时仍会平滑切换。
- 界面中的名称、状态、版本和路径等组合信息现在改用空格分隔，文字显示更简洁。

## 改进

- 自定义块属性面板现在直接依据块资源自身的字段定义和公开字段配置显示属性；公开的宽度字段不再被通用隐藏规则错误遮挡，未公开字段仍不会出现在编辑器和运行时覆盖中。

## 修复

- 删除包含子块的结构后，会同步清理所有卡牌实例中对应的无效字段覆盖数据，避免实例数据残留已不存在的块。

- 已安装自定义块页面的列表和预览区域现在会正确填满可用高度，不再挤在页面顶部。
- CSS 长度字段现在可以正确接受负数值，不再错误显示渲染警告。
- 树形列表的操作浮窗现在会直接出现在触发位置，不再从窗口左上角闪现。
- 未选择项目图标集时，右侧的提示现在会正确显示在可用区域中央。
- 侧边栏树在节点内容与空状态提示之间切换时会保持可用高度，刷新时间线等内容时不再引起面板抖动。
- 未启用 Git 的项目不再短暂显示“正在加载时间线”，打开或切换编辑器时侧边栏中的其他列表也不会因此跳动。
- 新建文本块的空富文本不再包含额外的换行。
- 底部面板的圆形控制按钮现在固定在窗口右下角，编辑卡牌内容时不会再影响画布区域的位置。
