# 新增

- 外观设置现在可以分别调整深色与浅色主题的主题色、背景色和前景色，其他界面层级会自动生成；主题色会同步应用到按钮、选中状态、焦点和代码编辑器，预览窗口也会使用与真实窗口一致的配色。

# 改进

- Instance 属性面板不再显示 Block 名称编辑项；Block 名称统一由 Blueprint 与结构树管理，避免看似局部的修改影响共享结构。
- 层级视图中的卡面基板现在使用当前主题色描边，更容易辨认卡牌的实际边界。
- 默认主题色更新为更鲜明的紫色，欢迎页动画、按钮、选中状态与代码编辑器会统一使用新配色。
- 欢迎页的 Logo 与 OpenCard 字标现在会使用当前主题色及可调相位角的邻近色呈现平滑明度动画，加载完成后会从透明状态自然淡入，减少动态时直接显示静止着色结果。
- 项目文件树、卡牌结构树、数据表、画布选区和属性分类现在支持右键快捷操作，也可以通过菜单键或 Shift+F10 打开；原有按钮和快捷键保持不变，指针离开菜单后菜单会自动收起。
- 卡牌结构树现在可以像项目文件树一样，通过双击父节点快速展开或收起内容。
- 外观设置的主题预览改为更简洁的抽象界面，减少无关文字和模拟内容，更容易观察颜色、层级与玻璃效果。
- 改进卡牌编辑器的层级视图：按 Tab 打开后，左上角会显示整张卡牌的缩略预览，图层堆栈会补充卡面基板，透明背景和负层内容也更容易辨认；右侧分段标尺会清晰标出各层级，并让当前层级和聚焦节点始终对齐，浏览复杂图层时更加直观。
- 图片和其他文件路径现在支持逐级浏览目录，并会根据用途筛选可用文件。选中文件后，可以从候选列表取消选择并返回所在目录。
- 项目文件树会提前读取可见文件夹的下一层，未展开的文件夹也能显示直属项目数量和展开入口。
- 属性面板的分类排序与字母排序合并为一个切换按钮，操作更加直观。
- 外观预览更直观：数据瀑布移至模拟标题栏，编辑区使用缓慢滚动的噪波点阵并延伸到玻璃侧面板下方，中央示例简化为小圆角的梅花 7 扑克牌。
- 优化富文本描边效果，较粗的描边不再侵蚀文字内部和前景色。

# 修复

- 修复层级视图中相同 zIndex 的 Block 前后顺序与实际卡面覆盖顺序相反的问题。
- 修复调整二维码 Block 层级时，层级视图左上角预览会短暂显示错误占位的问题。
- 修复欢迎页 OpenCard 字标可能横向铺满标题区域的问题；动画图像现在会按适配模式正确保持比例、裁切或拉伸。
- 修复柔和按钮悬停时文字与背景混成同色，以及小尺寸按钮可能裁掉下伸字符的问题。
- 修复浅色主题下部分原生控件仍显示暗色样式的问题。
- 修复文件路径候选偶尔跳回项目根目录、重复聚焦时结果不一致的问题。
- 修复输入部分路径时仍会显示无关文件，以及选中完整文件后仍显示普通目录候选的问题。
- 修复数据表正面和背面标题行背景没有完整铺满的问题。
- 修复暗色主题下开关、滑块等控件悬停时出现突兀黑边的问题。
- 修复属性面板删除按钮在部分语言下缺少提示文字的问题。
