# 新增

- 新增“反馈与建议”窗口，可从帮助菜单或“关于 OpenCard”页面发送问题与建议，并查看这台设备上的提交记录、处理状态和官方答复。
- 报告问题时可以选择附带诊断信息；发送前可查看具体内容，本机路径、账号和凭据等敏感信息会自动隐藏。
- 深色与浅色外观各新增 5 套内置主题，可一键切换整套配色和次级颜色相位角。
- 主题支持导入和导出；导入的主题会加入预设列表，也可从列表中删除。
- 外观设置新增基准字号与字体选择，可为深色和浅色外观分别设置系统字体及回退字体。

# 改进

- 卡牌数据表使用统一行高，数据列可通过拖动或键盘调整宽度，并会保持在易读范围内。
- 应用标题栏仅保留 OpenCard 名称，不再重复显示品牌图标。

# 修复

- 浏览器标签页会正确显示 OpenCard 图标，不再出现开发工具的默认图标。
