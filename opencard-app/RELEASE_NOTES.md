# 改进

- 图片和其他文件路径现在支持逐级浏览目录，并会根据用途筛选可用文件。选中文件后，可以从候选列表取消选择并返回所在目录。
- 项目文件树会提前读取可见文件夹的下一层，未展开的文件夹也能显示直属项目数量和展开入口。
- 属性面板的分类排序与字母排序合并为一个切换按钮，操作更加直观。
- 优化富文本描边效果，较粗的描边不再侵蚀文字内部和前景色。

# 修复

- 修复文件路径候选偶尔跳回项目根目录、重复聚焦时结果不一致的问题。
- 修复输入部分路径时仍会显示无关文件，以及选中完整文件后仍显示普通目录候选的问题。
- 修复数据表正面和背面标题行背景没有完整铺满的问题。
- 修复暗色主题下开关、滑块等控件悬停时出现突兀黑边的问题。
- 修复属性面板删除按钮在部分语言下缺少提示文字的问题。
