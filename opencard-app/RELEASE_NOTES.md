## 改进

- 项目文件树中的项目配置、字体注册表、图标注册表和全局字典现在将说明文字作为标题、文件名作为尾部文本，文件图标仍与文件名保持对应，并固定使用系统约定文件名且不可重命名。
- 文件树中的普通文件重命名现在会自动选中文件名主体，保留扩展名不被误改。
- 简单容器和流式容器现在可以打包为结构树和数据表中的单一节点；包内内容仍会正常显示，需要编辑内部 Block 时可随时解包。
- 可以将任意 Block 导出为可移植的自定义 Block；导出会正确处理完整子树中的自定义字段定义，可从项目配置或文件树创建、打开项目注册表，再在其他卡牌中快速插入和复用。
- 改进自定义 Block 的资源打包与加载可靠性；重复图片会去重，嵌套自定义 Block 可正确重新导出，损坏或超限归档会在加载前拒绝，项目切换时不会被旧加载结果覆盖。
