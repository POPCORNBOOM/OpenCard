# 新增

- CardEditor 新增按 session 保存的数据表视图，可选择需要集中编辑的 Block 与字段，并按列批量编辑蓝图和实例、管理实例与重置覆写。
- CardEditor 新增按住 Tab 展开的 zIndex 层级视图，支持平面滚动、拖拽、Layer Ruler、按名称首字母循环和快捷调整层级。
- 富文本工具栏新增字号选择，并以 TextBlock 字体与字号作为局部格式的默认值。

# 改进

- 数据表只为已加入的字段构造 Cell，并在进入滚动视口附近后才挂载字段编辑器，降低大型卡牌文档的初次加载开销。
- 标题栏任务进度在开始和结束时使用淡入淡出过渡，避免突然出现或消失。
- 图片资源字段的自动补全只显示文件名，同时继续写入完整相对路径。
- 层级视图以聚焦平面为单一导航真相，统一滚轮、方向键、Space 与 Shift 组合操作，并在激活时弱化侧边栏。
- 层级视图的名称快捷导航支持中文 Block 名的拼音首字母，并用图标显示滚轮、Space 和 Shift 提示；滚轮与方向键明确标记为替代操作，Layer Ruler 与平面堆保持清晰间距。
- 项目字体管理显示每个 font face 的字段标签和加载错误，同时保留其他可用字体。
- 项目字体使用稳定 CSS family 别名，并自动兼容 0.2.9 已保存的富文本字体引用。

# 修复

- 修复 macOS 和 Linux 无法访问隐藏 OpenCard 路径、导致内置模板加载以及项目简介和字典创建失效的问题。
- 修复将 OpenCard 草稿保存到当前项目后文件树未立即显示新文件的问题。
- 修复项目字体在 Tiptap 样式合并中被带冒号 family 拆分、失效字体缺少反馈的问题。
- 修复层级视图只有一个平面时 Space+滚轮无法调整 zIndex，以及非预设字号未出现在富文本字号下拉中的问题。
