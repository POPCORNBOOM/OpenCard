# 新增

- 卡牌数据表支持导入和导出 Excel 表格，可选择参与导出的实例；未覆写的实例值会引用蓝图，重新导入后仍保持继承关系。
- 新增“反馈与建议”窗口，可从帮助菜单或“关于 OpenCard”页面发送问题与建议，并查看这台设备上的提交记录、处理状态和官方答复。
- 报告问题时可以选择附带诊断信息；发送前可查看具体内容，本机路径、账号和凭据等敏感信息会自动隐藏。
- 深色与浅色外观各新增 5 套内置主题，可一键切换整套配色和次级颜色相位角。
- 主题支持导入和导出；导入的主题会加入预设列表，也可从列表中删除。
- 外观设置新增基准字号与字体选择，可为深色和浅色外观分别设置系统字体及回退字体。

# 改进

- 数据表中参与 Excel 导出的实例图标现在会跟随当前主题色，排除导出时仍以弱化状态显示。
- 项目文件、卡牌实例、Block 和字典键的重命名现在会在输入框失去焦点时自动提交，按 Esc 可取消修改。
- 数据表的 Excel 导入与导出按钮移至工作区操作栏，与设计/数据表视图切换并列，表格顶部不再额外占用空间。
- 优化数据表的背景层级，Face、Block 和字段现在分别形成连续的横向分组，不再出现固定行头与数据单元格颜色割裂的问题。
- 数据表的 Block 与字段操作现在明确区分“加入表格编辑”“不再使用表格编辑”和“永久删除”，右键菜单与行内按钮使用一致的命令层级和提示文字。
- 卡牌数据表不再将已经显示在行头的 Block 名称重复列为字段，表格内容更加聚焦于可批量编辑的数据。
- 卡牌数据表的表头、Face、Block 和字段行现在使用统一且稍宽松的高度，数据列可通过拖动或键盘调整宽度，并会保持在易读范围内。
- 应用标题栏仅保留 OpenCard 名称，不再重复显示品牌图标。

# 修复

- 修复多级菜单深处的选项点击后没有反应的问题，卡牌结构树现在可以通过行内菜单或右键菜单正常添加子块。
- 修复数据表中的富文本字段上下显示不完整、与其他字段对齐不一致的问题。
- 浏览器标签页会正确显示 OpenCard 图标，不再出现开发工具的默认图标。
