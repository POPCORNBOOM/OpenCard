# 新增

- 项目简介新增独立的项目字体管理，可导入并注册多个字体文件供卡牌、富文本和导出统一使用。
- 新增项目级远程资源策略，支持禁止、域名白名单和允许全部 HTTPS 资源，并为白名单格式提供内嵌提示。
- 属性编辑器新增删除模式，可移除非必填字段并同步清理实例覆盖数据。

# 改进

- 富文本与 Markdown 文本现在能正确保留连续空格，并完善下划线、删除线等格式编辑体验。
- 恢复结构树节点展开时的图标旋转反馈，改进卡牌选择、移动与快捷操作体验。
- 改进标题栏任务进度、导出反馈及项目配置界面，使长时间操作的状态更清晰。

# 修复

- 修复部分可选字段未显示删除入口、Tree 展开状态缺少视觉反馈等问题。
