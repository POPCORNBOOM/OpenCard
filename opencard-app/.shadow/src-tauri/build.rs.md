# 构建资源暂存边界

Tauri 会把内置模板和图标包复制到 `target/<profile>`，但目录映射只覆盖同名文件，
不会删除源码中已经移除的旧资源。旧项目结构文件一旦残留，就会继续进入开发运行或安装包。

构建脚本只可清理由当前构建配置拥有的 `target/debug` 或 `target/release` 下的
`templates`、`icon-packs` 暂存目录，并必须先验证 `OUT_DIR` 的祖先结构；不能把清理范围
扩展到整个 profile、`target`、源码资源目录或任意环境变量路径。清理发生后再由 Tauri
从当前源码资源重建暂存内容，使删除和移动也能可靠生效。
