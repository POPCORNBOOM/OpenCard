`tree.types.ts` 是树交互协议的“无运行时依赖边界层”：
- 只允许放稳定协议类型（节点结构、action 载荷、拖拽与重命名 payload、注入上下文契约）。
- 禁止放业务规则与 UI 组件实现细节。

设计目的：
- 让 `core/store/composables` 可以共享树协议而不反向依赖 `components/ui`。
- 把“可复用协议”和“组件实现”彻底分离，避免再次出现类型定义绑在 `.vue` 文件里的层级反转。

演进约束：
- 新增字段优先做向后兼容，不要轻易重命名已有 payload key。
- 如果语义变化必须破坏兼容，先同步所有调用方，再改协议注释与 shadow。
