`useIdeFileTree.ts` 负责 IDE 左侧树的壳层投影与选中同步：
- 把项目索引转换为 UI 树节点（含图标与目录展开态映射）。
- 维护“项目树选中 + 已打开编辑器树选中”两组状态。
- 监听活动会话路径并同步两棵树的选中投影。

边界约束：
- 这里只处理“视图投影与交互编排”，不写文件系统规则本体。
- 文件移动/重命名合法性与持久化仍在 workspace store。
- 会话 preview/fixed 语义仍在 editorSessionStore。

稳定性约束：
- 路径比较必须走标准化（`\\` -> `/`，去尾斜杠）以避免跨平台选中抖动。
- 选中同步必须容忍节点暂时不存在（索引刷新中），不能抛异常。
