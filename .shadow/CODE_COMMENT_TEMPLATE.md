`NodeTree` 风格代码注释模板（Vue SFC）

顶部块注释模板（放在 `<template>` 前）：
```vue
<!--
  使用说明：
  - <如何使用该组件，列 1-3 条关键输入约束>
  - <关键交互或调用方式>

  职责边界：
  - 负责 <本组件负责的交互协议/状态机/渲染职责>
  - 只 <上抛意图/返回结果>，不 <业务落库/领域规则>

  主要输出事件：
  - `<事件名 A>`（<语义>）
  - `<事件名 B>`（<语义>）
-->
```

脚本内注释模板（短句单行，放在声明块前）：
```ts
// Vue 基础能力与依赖组件。
// 组件输入协议。
// 对外事件协议。
// 运行时状态。
// 外部受控状态同步。
// 派生状态与索引。
// 交互动作：<动作名>。
// 工具函数：<用途>。
```

风格约束：
- 注释写“协议/边界/意图”，不复述显而易见实现。
- 使用短句中文，句末 `。`，不使用 `====` 分隔。
- 分块命名用名词短语，和 `NodeTree.vue` 保持一致语气。
- 优先解释“为什么这样设计”，其次才是“做了什么”。
