# OpenCard 运行时数据流

## 编辑器

```mermaid
flowchart LR
    Host["Editor Host"]
    Editor["当前活动 Editor"]

    Host <-->|"数据与命令向下　修改与意图向上"| Editor

    linkStyle default interpolate stepAfter
```

- **Editor Host**：持有 session，并管理 Editor 和外部功能。
- **Editor**：展示和修改数据，需要外部操作时通知 Host。

具体通信：

- Host → Editor：`props`、`navigate(token)`
- Editor → Host：`update:modelValue`、`EditorIntent`
