# OpenCard

OpenCard 是一个基于 **Tauri + Vue 3 + TypeScript** 的桌面卡牌编辑器，目标是提供“文件系统可见、可视化编辑与文本编辑并存”的卡牌制作体验。

## 当前已实现功能

1. IDE 壳层
- 多标签编辑区（支持打开、切换、关闭文件会话）
- 左侧活动栏与文件浏览器
- 全局保存快捷键（`Ctrl/Cmd + S`）

2. 项目文件管理
- 打开本地项目文件夹
- 文件树展示与目录展开状态维护
- 文件/目录拖拽移动与重命名
- 项目文件监听（变更后自动刷新索引）

3. 编辑器系统
- Monaco 文本编辑器（代码/文本文件）
- 卡牌可视化编辑器（`.opencard`）
- 图片预览编辑器

4. 卡牌领域模型
- 支持 `text-block`、`image-block`、`simple-container-block`、`flow-container-block`
- 支持卡牌文档尺寸、层级、定位、样式、容器嵌套
- 支持文档导入归一化与渲染前安全物化

5. 卡牌可视化编辑能力
- 结构树选择、重命名、增删、复制、拖拽重排
- 画布缩放、平移、选中框交互
- 选中块移动与尺寸调整
- 属性面板按分类/A-Z 展示并支持新增字段、重置字段

6. 实例系统
- 蓝图与实例分离编辑
- 支持实例新建、复制、删除、重命名、排序
- 支持按实例覆盖字段值，不污染蓝图

7. 引用解析系统
- 支持模板引用语法：`{{p:field}}`、`{{p.p:field}}`、`{{d:field}}`
- 支持循环检测、字段权限校验、类型校验与问题收集

8. 导出能力
- 导出当前蓝图为 PNG（2x 流程）
- 批量导出蓝图 + 全部实例 PNG
- 导出前自动执行实例投影、引用解析、资源等待与文件名去重

9. 国际化
- 内置中文、英文文案

10. 测试
- 已有 Vitest 单元测试覆盖引用解析、树操作、实例覆盖、面板尺寸逻辑等核心模块

## 主要目录

- `opencard-app/`：前端与 Tauri 应用主体
- `opencard-app/src/`：Vue 页面、组件、状态与领域模型
- `opencard-app/src-tauri/`：Tauri/Rust 侧命令与能力配置

## 本地开发

```bash
cd opencard-app
npm install
npm run dev
```

## 构建与测试

```bash
cd opencard-app
npm run build
npm test
```
